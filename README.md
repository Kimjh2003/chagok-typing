# 차곡 타자

**손끝으로 쌓는 오늘의 한 문장.** 평소 쓰는 시스템 키보드로 한국어와 영어를 연습하는 Android 타자 연습 앱입니다. 로그인이나 인터넷 연결 없이 기기에서 연습하고 결과를 확인할 수 있습니다.

## 주요 기능

- **한국어·영어 연습:** 단어와 문장을 선택하고 제시문을 따라 입력합니다. 문단 제시문과 기존 문단 기록도 코드에서 지원하지만, 현재 홈 선택 화면에는 단어와 문장만 표시됩니다.
- **시스템 키보드:** 앱 자체 키보드 대신 사용자가 선택한 IME를 사용합니다. 설정에서 엔터로 연습을 완료할지 선택할 수 있습니다.
- **실시간 상태:** 입력 진행률, 경과 시간과 현재 입력 기준 타/분을 보여줍니다. 연습 완료 후 입력 내용과 결과를 확인할 수 있습니다.
- **기기 내 기록:** 결과를 SQLite에 저장하고, 언어·종류별 최근 기록을 살펴보거나 여러 기록을 선택해 삭제할 수 있습니다.
- **화면 대응:** 라이트·다크 모드와 화면 크기에 따른 배치를 지원하고, 키보드 영역과 시스템 인셋을 반영합니다. 폴더블 힌지의 실제 위치를 감지해 피하는 기능은 아직 구현되지 않았습니다.

## 타수 계산

타수는 실제 키보드 터치 횟수가 아니라 **현재 입력에 남아 있는 텍스트를 환산한 값**입니다. 삭제한 과거 입력은 누적하지 않고, 붙여넣기와 자동 수정 결과도 현재 텍스트로 계산합니다. 속도는 `환산 타수 × 60,000 ÷ 활성 연습 시간(ms)`이며, 실시간 표시는 시작 후 1초 동안 ‘측정 중’으로 나타납니다.

- **한국어:** 한글 자모를 기준으로 세고 복합 모음과 겹받침은 2타, 쌍자음은 1타로 계산합니다. 영문·숫자·기본 문장부호·공백도 각각 1타입니다.
- **English:** 영문·숫자·기본 문장부호·공백을 각각 1타로 세고 한글과 줄바꿈 등은 제외합니다. WPM이 아닌 타/분으로 표시합니다.
- **일치율:** 원문과 입력을 비교해 계산하는 별도 지표입니다. 기존 기록의 값은 새 정책으로 다시 계산하지 않습니다.

계산과 저장 방식의 자세한 내용은 [입력 로직](INPUT_LOGIC.md)과 [기록 저장](RESULT_HISTORY.md)을 참고해 주세요.

## 구성

| 모듈 | 역할 |
| --- | --- |
| `:app` | 화면, 내비게이션, 키보드·생명주기 연결 |
| `:practice` | 순수 Kotlin 연습 상태, 언어별 타수, 점수와 제시문 |
| `:history` | 로컬 연습 기록과 SQLite 저장 |
| `:ui` | 공통 UI, 색상, 입력 카드와 화면 배치 |
| `:motion` | 화면 전환 및 시스템 키보드 연동 모션 |
| `:common` | 공통 크기 변환 |
| `:smoke` | 릴리즈 APK 검증용 별도 테스트 앱 |

모듈 경계는 [MODULES.md](MODULES.md), 디자인은 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)를 참고해 주세요.

## 빌드와 테스트

Android Studio에서 이 폴더를 프로젝트로 열 수 있습니다. 현재 설정은 **Android SDK 37**, **minSdk 28 (Android 9)**, Gradle Wrapper 9.7.1과 Gradle daemon JVM 25를 사용합니다. SDK와 Gradle 의존성이 없다면 최초 동기화 시 다운로드가 필요할 수 있습니다. 이 설정은 상위 Android 버전 설치 제한을 두지 않습니다.

Windows PowerShell에서:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :practice:test :app:testDebugUnitTest :ui:testDebugUnitTest
```

디버그 APK는 `app/build/outputs/apk/debug/`에 생성됩니다. 개인 테스트용으로 R8과 리소스 축소가 적용된 릴리즈 APK를 만들려면:

```powershell
.\gradlew.bat :app:assembleRelease -PlocalTestingSigning=true
```

이 옵션은 로컬 Android 디버그 키를 쓰는 **테스트용 서명**입니다. 정식 배포 서명과 키 관리 방법은 [DISTRIBUTION.md](DISTRIBUTION.md)와 [R8.md](R8.md)를 참고해 주세요. APK 업데이트에는 서명 호환성이 필요하며, 키스토어나 비밀번호를 저장소에 올리지 않아야 합니다.

## 검증과 참고 문서

단위 테스트와 Android 계측 테스트 소스가 포함되어 있습니다. 기기·IME·화면 크기마다 실제 동작이 다를 수 있으므로 폴더블, 여러 키보드와 Android 버전에서의 추가 실기기 검증이 필요합니다. 성능 최적화는 기기별 지연이나 프레임 개선을 보장하는 측정 결과가 아닙니다.
